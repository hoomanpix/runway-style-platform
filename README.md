# Runway Style Platform

Runway Style Platform is a monorepo scaffold for building fashion-related tools and services. This repository provides an initial project structure for apps, backend services, shared packages, documentation, and infrastructure.

Structure:

- apps/      — mobile, web and admin applications
- backend/   — API, workers, AI components, services, database code and shared modules
- packages/  — shared UI components, TypeScript types, utilities, and configuration
- docs/      — project documentation
- infra/     — infrastructure-as-code and deployment configs

This commit only initializes the repository layout. No executable code, dependencies, or CI workflows are included.
